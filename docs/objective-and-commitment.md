# Objetivo y Compromiso del MVP

## Objetivo

Construir un MVP generalista de plugin QGIS para vectorizar imágenes raster en local, con prioridad en precisión máxima y salidas geoespaciales confiables para uso productivo.

## Compromiso del equipo

1. Precisión primero, velocidad después.
2. Reproducibilidad por encima de ajustes ad hoc.
3. Decisiones técnicas trazables y documentadas.
4. Entregas incrementales con criterios de aceptación claros.
5. Arquitectura lista para crecer a múltiples motores de vectorización.

## Definición de éxito del MVP

- El plugin procesa imágenes de distintos tipos con perfiles predefinidos.
- La salida es válida y utilizable directamente en QGIS.
- Existe baseline de calidad con dataset de referencia y métricas.
- El diseño deja preparado el camino para añadir IA al final sin refactor mayor.
